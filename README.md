# 🌐 Web Landing Page

Interface web responsiva desenvolvida com HTML5, CSS3 e JavaScript para demonstração de layout e interatividade front-end.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação)
* **CSS3** (Estilização e Layout)
* **JavaScript** (Interatividade)

---

## 💻 Como Visualizar o Projeto

1. Clone o repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` diretamente em qualquer navegador web de sua preferência.
